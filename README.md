# Tim Corey Course Practice

Practice projects created while following along with Tim Corey's C# course. These projects are focused on reinforcing C# fundamentals, Object-Oriented Programming, and .NET development concepts through hands-on coding.

## Purpose

The goal of this repository is to practice concepts by building projects alongside the course, understanding the code structure, and gradually improving my ability to write C# applications independently.

## Projects

### Mini Project - Inheritance & Interfaces

- **Concepts practiced:**
  - Inheritance
  - Interfaces
  - Polymorphism
  - Object-oriented design

- **Original project:** Followed Tim Corey's rental/purchase system using `IRentable` and `IPurchasable` interfaces (`VehicleModel`, `BookModel`, `ExcavatorModel`).

### Mini Project - Card Game

- **Concepts practiced:**
  - Access modifiers
  - Abstract classes
  - Method overriding
  - Enums
  - Collections (`List<T>`)
  - Object creation and relationships between classes

- **Description:** Built a card game application while following the course to practice creating classes, managing objects, and applying OOP concepts in C#.
